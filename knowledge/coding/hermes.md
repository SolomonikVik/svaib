# Hermes Agent

## Кратко

Hermes Agent — открытый харнесс с Python-плагинами, shell-хуками, импортом ресурсов других агентов и MCP. Импорт Claude/Codex-инструкций и скиллов не устанавливает автоматически весь исходный плагин. Для собственного провайдера важен минимальный допустимый контекст, а для shell-хуков — согласие на точную пару события и команды.

## Плагин и импорт

Нативный Python-плагин задаётся `plugin.yaml` и функцией `register(ctx)`, которая регистрирует инструменты и обработчики. Поддержка переносимого plugin manifest не означает поддержку Claude-манифеста в `.claude-plugin`. См. [плагины Hermes](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/features/plugins.md).

`import-agent` переносит поддерживаемые инструкции, скиллы и конфигурацию исходного агента. Перенос Markdown не доказывает загрузку исходного hook registry или агентных профилей. Повторный `import-agent --sync` — явное действие синхронизации; наличие этой команды не подтверждает автоматическое получение будущих релизов marketplace.

Обнаружение MCP, согласие на подключение и OAuth проверяются отдельно. Проектные Python-плагины по умолчанию отключены; их включение предназначено для доверенных проектов. Плагин, работающий внутри процесса, разделяет права и доступ этого процесса.

## Shell-хуки и Python

Для запуска отдельного Python-скрипта не обязательно создавать Python-плагин: профиль `config.yaml` принимает блок `hooks`. В нём используется точное событие из Hermes, например `pre_tool_call`, и команда. Command запускается как subprocess; для передачи данных используется JSON на stdin и JSON на stdout. См. [shell-хуки](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/features/hooks.md#shell-hooks).

Первое исполнение требует согласия на пару `(event, command)`; после смены события или команды прежнее разрешение нельзя считать достаточным. Неодобренный хук пропускается. Это нужно проверить до вывода, что скрипт несовместим с харнессом.

Shell-хуки могут блокировать или менять tool call, добавлять контекст перед модельным запросом и наблюдать жизненный цикл. Часть ответов Claude-стиля распознаётся, но это не обещание полной эквивалентности: нужно сопоставить event, native tool name, аргументы и формы решений. `action: approve` в Hermes означает обращение к человеческому гейту, а не произвольное auto-allow. Таймаут и `fail_closed` также входят в контракт.

Предметную Python-логику можно сохранять. Адаптация деклараций и полезной нагрузки остаётся обязательной там, где исходный скрипт ожидает другой харнесс. Общие различия описаны в [контрактах хуков](../plugins/cross-harness-hooks.md).

## Контекст провайдера

В обычном пути инициализации Hermes действует минимальное окно 64 000 токенов. Модель с меньшим доступным окном может быть отвергнута ещё до запроса к провайдеру. В коде предусмотрены отдельные условия для локальных серверов и явно настроенного LM Studio, поэтому порог нельзя без проверки объявлять универсальным для каждого backend. См. [проверку минимума](https://github.com/NousResearch/hermes-agent/blob/main/agent/agent_init.py) и [метаданные модели](https://github.com/NousResearch/hermes-agent/blob/main/agent/model_metadata.py).

`model.context_length` в `config.yaml` должен описывать реально обслуживаемое окно выбранного endpoint. Исправление отсутствующих метаданных — допустимая настройка; завышение лимита тарифа ради прохождения гейта делает проверку недостоверной. Для неподходящего окна нужен другой backend или тариф с достаточным контекстом, а не фиктивное число.

Лимит выхода следует проверять по настройке активного runtime и фактическому запросу. Успешный запуск с большим окном не доказывает, что все интерфейсы запуска одинаково применяют параметры модели. См. [контракт исполнения](agent-runtime-contract.md).

## Лицензия и интеграция

Hermes распространяется по [MIT](https://github.com/NousResearch/hermes-agent/blob/main/LICENSE). Условия провайдера независимы от лицензии харнесса. ACP позволяет подключить оболочку, но не делает её владельцем plugin runtime; роль интерфейса описана в [BB](../tools/bb.md).
