# OMP — Oh My Pi

## Кратко

OMP — открытый агентный харнесс с собственным marketplace, совместимым с каталогами Claude Code. Он обнаруживает скиллы, команды, агентов и MCP из установленного пакета, но Claude command-хуки не исполняет через `hooks.json`. Их Python-логику можно сохранить, подключив к событиям OMP через расширение.

## Marketplace и ресурсы

Каталог marketplace читается из `.omp-plugin/marketplace.json` либо совместимого `.claude-plugin/marketplace.json`. Источниками могут быть Git, локальный каталог или прямой URL каталога. Пользовательская и проектная установки имеют отдельные реестры; включённая проектная установка может перекрывать пользовательскую. Нативная установка marketplace отличается от установки npm-пакета расширения. См. [marketplace](https://github.com/can1357/oh-my-pi/blob/main/docs/marketplace.md).

Обнаружение ресурсов идёт по их собственным правилам. Загрузка навыков и объявлений MCP из Claude-пакета не означает загрузку его хуков. Агентные Markdown-профили читаются отдельно; стандартные имена встроенных инструментов нормализуются в имена OMP. Это позволяет сохранить исходный профиль скаута, но наследование контекста, доступные инструменты и выполнение задания всё равно требуют проверки.

Импорт пользовательских настроек чужого харнесса может требовать opt-in. Это другой механизм, чем включение установленного через собственный marketplace OMP плагина. Пропущенный Claude `hooks.json` нельзя объяснять только отсутствием ручного согласия: сначала нужно проверить, поддерживает ли загрузчик этот файл.

## Хуки и Python

В исполняемый механизм расширений попадают JS/TS-фабрики, обнаруженные в `hooks/pre` и `hooks/post`; фабрика сама регистрирует обработчики событий. Директория и имя файла дают метаданные обнаружения, но не заменяют `pi.on(...)`. JSON со списком Claude command-хуков этим механизмом не интерпретируется. См. [хуки](https://github.com/can1357/oh-my-pi/blob/main/docs/hooks.md).

Общий мост может запускать исходные Python-команды, переводить названия инструментов и поля аргументов, подавать `additionalContext` в модель и превращать отказ обработчика в блокировку native tool call. Событие `session_stop` позволяет запросить продолжение или отказать в завершении. Для обработчика, читающего Claude JSONL, нужна проекция нативной истории либо поддержка полей самого события; `stop_hook_active` сохраняет защиту от повторного продолжения. См. [extension API](https://github.com/can1357/oh-my-pi/blob/main/docs/extensions.md) и [контракты хуков](../plugins/cross-harness-hooks.md).

Это позволяет переиспользовать Python без переписывания предметной логики. Мост остаётся исполняемым компонентом с отдельными обязанностями: доставка контекста, семантика отказа, таймауты, состояние сессий и обработка ошибок.

## Обновления и активация

`marketplace update` освежает каталог; `plugin upgrade` обновляет установленные плагины. Режим `marketplace.autoUpdate` задаёт `off`, `notify` или `auto`. Проверка при запуске освежает устаревшие каталоги; автоматическое сравнение опирается на версии, явно указанные в каталоге. `notify` пишет доступность обновлений в debug log, что не равно заметному пользователю уведомлению. См. [правила обновления](https://github.com/can1357/oh-my-pi/blob/main/docs/marketplace.md#updates-removal-and-scope).

Обновление на диске и активация в текущей сессии различаются. Перезагрузка ресурсов обновляет часть каталогов; новые хуки, инструменты и extension modules требуют перезапуска. ACP/RPC-обработчики marketplace обновляют определённые ресурсы, но не пересобирают все уже инициализированные компоненты и не гарантируют переподключение MCP.

## Границы доверия

OMP не имеет эквивалента отдельного Pi-гейта доверия проектной папке: проектные ресурсы загружаются по правилам OMP, а совместимый `isProjectTrusted()` возвращает `true`. Это не свидетельство ограничения доступа файловой системой. Политика разрешений и изоляция процесса должны проверяться самостоятельно. См. [контекст расширения](https://github.com/can1357/oh-my-pi/blob/main/packages/coding-agent/src/extensibility/extensions/types.ts).

OMP распространяется по [MIT](https://github.com/can1357/oh-my-pi/blob/main/LICENSE). Условия провайдера и региональная доступность рассматриваются отдельно от лицензии CLI. Интеграция оболочки описана в [BB](../tools/bb.md), критерии приёмки — в [контракте исполнения](agent-runtime-contract.md).
