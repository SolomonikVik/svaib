# Paperclip

## Кратко

Open-source (MIT), self-hosted платформа-оркестратор AI-агентов, где ты запускаешь не одного бота, а целую **компанию** из агентов: org chart с ролями (CEO, CTO, инженеры, дизайнеры, маркетологи), цели, бюджеты и governance. Node.js-сервер + React-дашборд, встроенный Postgres. Agent-agnostic: любой бот, любой провайдер — «если принимает heartbeat, значит нанят». Ключевой фрейм авторов: **«OpenClaw — сотрудник, Paperclip — компания»** — слой оркестрации *над* автономными агентами. Появился в марте 2026, один из самых быстрорастущих open-source AI-проектов.

## Что это

Mental model: **компания, которой ты управляешь**, а не инструмент, который используешь. Paperclip моделирует организацию, в которой работают агенты — org chart, цели, бюджеты, управление. Оркестрирует команды: назначает роли, отслеживает затраты, требует апрувы, фиксирует артефакты, держит работу агентов привязанной к целям компании.

## Ключевые механизмы

- **Org chart и делегирование.** CEO / CTO / инженеры / дизайнеры / маркетологи. Делегирование ходит вверх-вниз по структуре автоматически.
- **Agent-agnostic.** Любой бот, любой провайдер; агенты приносят свои промпты, модели, runtime. Критерий найма — умение принимать heartbeat.
- **Бюджеты и контроль стоимости.** Токены и деньги трекаются по компании / агенту / проекту / цели / провайдеру / модели. Scoped-политики бюджета и hard-stop: при исчерпании агент останавливается и очередь отменяется автоматически.
- **Governance.** Владелец = совет директоров. Агенты не могут нанимать новых агентов без апрува; CEO не исполняет непроверенную стратегию.
- **Heartbeat.** Агенты просыпаются по расписанию, проверяют свою работу и действуют — автономная работа в фоне.

## Развёртывание

Локальный инстанс или удалённый деплой. Локально — один Node.js-процесс, который сам поднимает embedded Postgres и хранит данные в локальных файлах. MIT, self-hosted, без аккаунта Paperclip. Затраты — только API-плата за модели выбранного провайдера.
