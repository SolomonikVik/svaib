# STT-модели для русского языка

## Кратко

Сравнение моделей распознавания русской речи. В бенчмарке [AlphaCephei](https://alphacephei.com/nsh/2025/04/18/russian-models.html) (11 датасетов, 13 моделей, 2025) семейство GigaAM от Сбера — лидер с двукратным отрывом от Whisper: средний WER ~8% vs ~16%. На зашумлённом аудио (дальний микрофон, комната) разрыв больше: 4% vs 18%. Для встреч на русском GigaAM — первый кандидат в обоих сценариях.

**Про версии.** В бенчмарке тестировались **GigaAM2** (RNNT и CTC+LM). **GigaAM-v3** вышел позже и в этом замере не участвовал — приписывать ему цифры GigaAM2 нельзя. v3 остаётся кандидатом на пилот, но его качество нужно мерить самим.

**Про цифры.** WER сопоставим только внутри одного замера на одной выборке. Все числа в таблице open-source моделей ниже — из бенчмарка AlphaCephei, там сравнение корректно. Цифры из других источников помечены ⚠️. Заявленные вендором значения — не измерение.

---

## Ключевые выводы

1. **Специализированные русские модели обогнали мультиязычные.** В бенчмарке AlphaCephei GigaAM2 (240M параметров, MIT) точнее Whisper large-v3 (1550M) в 2+ раза на русском. Эпоха "Whisper для всего" закончилась.

2. **На зашумлённом аудио разрыв критический.** Golos Farfield (дальний микрофон): GigaAM 4,1% vs Whisper 17,6% — разница в 4,3 раза. Это именно сценарий "диктофон в переговорной".

3. **Whisper галлюцинирует на тишине.** Задокументированная системная проблема: на паузах и не-речевых сегментах Whisper генерирует несуществующий текст. Для встречных записей с паузами — критично. Обязателен VAD-препроцессинг.

4. **Диаризация — отдельная задача.** Ни одна open-source ASR-модель не включает нативную диаризацию. Стандартное решение: pyannote community-1 (language-agnostic, DER ~7% на meeting rooms).

### Бэкенды исполнения (важно для MacWhisper)

Whisper-модели могут исполняться через разные бэкенды с разной производительностью:

- **Whisper C++ (GGML)** — стандартный бэкенд, работает на любом железе (M1, Intel, GPU). Все размеры от Base (150 MB) до Large V3 (3 GB).
- **WhisperKit** — оптимизированный бэкенд для Apple Silicon (M1/M2/M3), использует ANE (Apple Neural Engine). Быстрее Whisper C++ на Apple Silicon. Доступны Small (483 MB) и Large v2 (3.1 GB). **Не работает на Intel Mac.**
- **Parakeet v3** (494 MB) — отдельная архитектура NVIDIA, **только Apple Silicon**. Экстремальная скорость (300x RT). Результаты по русскому есть в таблице выше: средний WER 16,0%, Farfield 7,6%, но провал на телефонии (29-32%).

На Intel Mac из локальных вариантов работает только Whisper C++ (и то медленно — терпимо лишь Small/Base). Решение для Intel — облачные API.

## Рекомендации по сценариям

### Онлайн-встречи (чистый звук)

**GigaAM.** Чистое аудио — сильная сторона: CommonVoice 2,6% (GigaAM2 RNNT), аудиокниги 3,4% (GigaAM2 CTC+LM). Вариант e2e RNNT выдаёт текст с пунктуацией и нормализацией без дополнительных модулей. 240M параметров, ~2 GB VRAM или CPU через ONNX. Для диаризации — pyannote community-1. Актуальная версия — v3, но её качество в бенчмарке не замерено.

Облачная альтернатива: **ElevenLabs Scribe v2** ($0,22-0,40/час, нативная диаризация, заявленный WER <= 5% на русском).

### Офлайн-встречи (микрофон в комнате, шум, несколько голосов)

**GigaAM + pyannote.** Именно здесь максимальный отрыв: Golos Farfield 4,1% (GigaAM2 CTC+LM) vs Whisper 17,6%. Модель дообучена на колл-центрах, голосовых сообщениях, речи с фоновой музыкой. В отличие от Whisper, не галлюцинирует на паузах (CTC/RNNT-архитектура).

Облачный fallback: **Yandex SpeechKit** ($0,08/час отложенно, SpeechKit Hybrid для on-premise).

### Стриминг (live-транскрипция)

**T-one** (71M параметров, Apache 2.0) — единственная open-source модель с нативным стримингом для русского. Чанки 300мс, задержка ~1с. Оптимизирован под телефонию, на wide-band аудио встреч может быть менее точен. Нет пунктуации — нужен отдельный модуль.

## Известные провалы

- **Whisper**: галлюцинации на тишине, потеря контекста на стыках 30-сек сегментов, WER 17-27% на зашумлённом русском
- **GigaAM**: только русский (на англ. — мусор), `.transcribe()` ограничен 25 сек (нужен `.transcribe_longform()` + pyannote), требует float32 на входе, нет стриминга
- **T-one**: нет пунктуации, нет нормализации, оптимизирован под 8 кГц телефонии, KenLM не работает на Windows
- **NVIDIA Parakeet v3**: катастрофа на телефонии/колл-центре (29-32% WER), русский добавлен недавно — мало пользовательского опыта
- **NVIDIA Canary v2**: худший результат среди всех на русском (средний WER 20,2%, колл-центр 34-36%)

## Облачные API (краткая сводка)

Цифры WER здесь — **не из бенчмарка AlphaCephei** и между собой несопоставимы: часть измерена на разных выборках, часть заявлена вендором и никем не проверена. Сравнивать эту таблицу с таблицей open-source моделей выше нельзя.

| Провайдер | Цена/час | Диаризация | WER (рус.), источник |
|-----------|------:|---|---|
| **Groq API** | Free tier | Нет | Whisper Turbo ~9,5% ⚠️ — расходится с 16,8% для той же модели в замере AlphaCephei; разные выборки, какая ближе к встречам — неизвестно |
| **ElevenLabs Scribe v2** | $0,22-0,40 | Нативная, до 32 спикеров | <= 5% (заявл.) |
| **Soniox API** | ~$0,10-0,12 | Нативная, code-switching | 6,2% ⚠️ |
| **Yandex SpeechKit** | $0,08-0,30 | Нативная, до 2 дикторов | Не опубликован |
| **AssemblyAI Universal-2** | $0,15 | +$0,02/час | <= 10% (заявл.), только batch |
| **Deepgram Nova-3** | $0,46-0,55 | +$0,12/час | Не опубликован |
| **Google Cloud STT** | $0,18-0,96 | Chirp 3 | Не опубликован |

**Groq API** — очень быстрый STT (216x RT на Whisper Turbo), бесплатный тир покрывает большинство задач, практичный вариант для Intel Mac, где локальные модели медленны. Для повседневной диктовки на русском — рабочий выбор.

Важно: это **инфраструктурный слой**, а не продукт для руководителя. Groq принимает аудиофайл или URL — он не записывает встречу, не разделяет сценарии и не доставляет результат в базу. В клиентской рекомендации по записи встреч ему места нет — см. [meeting-transcription.md](meeting-transcription.md).

**Soniox API** — заявленный WER 6,2% и нативный code-switching (русский + английский в одном потоке) — редкая функция, полезная для встреч с англоязычными терминами. Цифра из другого замера, с таблицей open-source моделей несопоставима. Малоизвестен, подключение через API. [Прайс](https://soniox.com/pricing).
