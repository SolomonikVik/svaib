# Подключить почту

Пользователь делает это с агентом на рабочем месте через MCP. Серверный партнёр может отправить результат на уже подтверждённый адрес собеседника.

## Подключение и смена адреса

1. Проверь текущий адрес и `get_email_verification`; продолжай по `next_step` из ответа. Если адрес подтверждён и действий не требуется, новый код не запрашивай. Отдельно скажи, доступна ли работа по почте: подтверждённый адрес сам по себе не означает, что канал компании включён.
2. По просьбе человека запиши новый адрес через `update_me(email=...)`. Смена адреса сразу отключает прежнюю почтовую привязку; новый адрес начнёт работать после подтверждения.
3. Если нужен новый код, вызови `request_email_verification` только с ключом повтора: адрес берётся из профиля, аргумента email нет. Сообщи фактический результат и `next_step`. Только при принятом запросе (`status=pending`) скажи: «Код запрошен на {адрес}. Посмотрите письмо и пришлите код». При лимите или отказе письмо не обещай; срок повтора бери из ответа. Очередь ещё не означает доставку.
4. Получи код от человека и вызови `confirm_email_verification`. Подтверждай успех только по результату инструмента.

После перерыва сначала прочитай статус. Для отправленного и ещё действующего запроса предложи посмотреть письмо; новый код без необходимости не запрашивай. Если срок истёк или попытки закончились, запроси новый код. Нужные challenge ID и ключи повторов передавай сам, человеку их не показывай.

Первый подтверждённый адрес владельца автоматически включает почтовый канал компании. Подтверждение адреса сотрудника само по себе канал не включает. Текущий статус показывает, доступна ли работа по почте.

## Написать партнёру

После подтверждения и включения канала отправьте вопрос с этого адреса на **partner@svaib.com**. Для нового вопроса создавайте новое письмо; для продолжения отвечайте в существующей цепочке. Истории писем и Telegram сохраняются отдельно.

Можно переслать текст письма и добавить задачу, например: «Предложи ответ». Разбор PDF и сканов пока не поддерживается.

## Получить результат на почту

В Telegram попросите: «Пришли этот результат мне на почту». На рабочем месте агент использует `send_email_message` с темой и выбранным текстом. Получатель — ваш собственный подтверждённый адрес.

`queued` означает очередь. При неопределённом исходе не повторяйте отправку с новым ключом: это может создать второе письмо. Агент сообщает неопределённость; проверка такого сбоя требует сопровождения платформы. Ответы приходят как HTML с текстовой версией.
