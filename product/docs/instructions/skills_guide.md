# Skills в Claude — как организовать и переиспользовать промпты

> **Runtime-зависимость:** этот гайд описывает Skills в экосистеме Anthropic Claude (Claude.ai, Cowork, Claude Code). При смене runtime механизм доставки skills изменится, но сами промпты (содержание) останутся.

## Что такое Skill

Skill — это набор инструкций, который Claude подгружает автоматически когда нужен. Главное отличие от Project Instructions: скилл глобальный — включил один раз, работает в любом чате, в любом проекте, в Cowork, в Excel/PowerPoint.

**Требование:** включить Code execution and file creation (Settings → Capabilities → Code execution and file creation → On)

**Как Claude использует скиллы:**
- **Автоматически** — сам определяет, когда скилл нужен, по описанию задачи
- **Явно** — можно написать "используй скилл meeting prep" или в Cowork набрать /
- В Excel/PowerPoint add-ins скиллы тоже доступны

## Как создать скилл

### Вариант А. Написать вручную

1. Возьми промпт, который уже работает (например, подготовка к планёрке)
2. Создай папку с понятным названием (например, `meeting-prep/`)
3. Внутри создай файл `SKILL.md` (формат Anthropic) — перенеси туда промпт, добавь шапку (name + description)
4. Запакуй папку в ZIP
5. Загрузить: **Customize** → **Skills** → **+** → **Upload a skill**
6. Включи тоглом — готово

### Вариант Б. Создать через разговор с Claude

1. Открыть новый чат в Claude
2. Написать: "Я хочу создать скилл для [описание задачи]"
3. Claude задаст вопросы о процессе, формате, примерах
4. Claude сгенерирует готовый файл скилла — скачать его
5. Загрузить: **Customize** → **Skills** → **+** → **Upload a skill**
6. Включить тоглом, протестировать

Можно загрузить примеры хороших результатов — Claude учтёт их при создании скилла.

### Вариант В. Получить готовый скилл от Виктора

1. Виктор подготовит и протестирует скилл
2. Передаст ZIP-файл
3. Загрузить: **Customize** → **Skills** → **+** → **Upload a skill**
4. Включить тоглом — готово

## Справочник

### Структура и формат

Минимум — папка с одним файлом `SKILL.md`. Опционально: шаблоны, примеры.

```
meeting-prep/
└── SKILL.md
```

Формат `SKILL.md`:

```markdown
---
name: "Подготовка к планёрке"
description: "Используй когда я прошу подготовиться к встрече с сотрудником"
---

Подготовь повестку встречи:
- Открытые задачи из прошлой встречи
- Ключевые метрики за период
- Вопросы для обсуждения
- Рекомендации по фокусу
```

Поле `description` — самое важное. По нему Claude решает, когда активировать скилл. Максимум 200 символов, писать конкретно.

### Советы

- Один скилл = одна задача. Не мешай "подготовку к встрече" и "обработку встречи"
- Можно добавлять файлы-шаблоны в папку — Claude их увидит
