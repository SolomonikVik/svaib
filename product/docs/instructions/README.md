# Пользовательские инструкции

Единственное место общих инструкций, по которым пользователь настраивает и осваивает svaib — сам или с помощью агента. Описания возможностей лежат уровнем выше в [docs](../README.md); внутренние процедуры внедрения — в playbook.

## Маршрут записи

- Новую общую пользовательскую инструкцию писать сюда; существующую исправлять на месте. У каждой — понятный `title` и `audience: client`.
- По одному действию — один источник технических шагов. Обзор или маршрут ссылается на подробную инструкцию, не повторяет её.
- Порядок этапов и признаки их прохождения задаёт [методология онбординга](../../methodology/onboarding/onboarding.md). Поведение скилла и запись отметок — [onboarding](../../plugin/skills/onboarding/SKILL.md).
- Внутренние операции внедрения ссылаются сюда. Персонализированные и отправленные экземпляры — в `clients/list/{client}/delivery/materials/` как история поставки, не источник общих правок.
- Перед передачей проверить отсутствие персональных данных других клиентов, доступов и внутренних указаний в теле. `source` в шапке — служебный адрес от корня репозитория; не включать его в пользовательский текст.
- Перенос не означает повторную проверку сведений о тарифах и интерфейсах: перед настройкой сверять актуальное с официальной документацией. Содержание `final` менять только после согласования точной правки.

## Доставка в онбординг

Состав копирования явно задан в manifest.txt: `@repo/product/docs/instructions/<файл> → skills/onboarding/references/<файл>`. В исходниках скилла этих копий нет. Собранные `references` вручную не редактируются; изменение делается здесь и приезжает следующей сборкой.

В онбординг включены рабочее место, Drive, git, Obsidian, контакты, транскрибация и подробная настройка MacWhisper. Остальные инструкции доступны для самостоятельной передачи по реестру выше. Этот README в клиентский пакет не копируется.

Следующий способ доставки — получение инструкций скиллом через MCP из этого же источника вместо копирования при сборке. Это согласованное направление, пока не реализовано.
