# Product — бэклог

## Кратко

Полный список задач направления на будущее. Источник для плана недели (`/svaib-strategy`). Задачи уже разобраны (из inbox) и ожидают выполнения.

Структура — по двум осям архитектуры (decision №4, 2026-04-27): **горизонталь** (общие слои) и **вертикали** (управленческие циклы). Скиллы и прочее — отдельно.

**Работа с файлом:** plan — дописывать по мере появления задач (из `_inbox/` при разборе, из встреч, из инсайтов). Выполненная задача — запись в [04_progress.md](04_progress.md), строка из бэклога убирается. Задача пишется с достаточным контекстом: понятно что делать без открытия других файлов. Что сюда: конкретные задачи развития direction'а. Что НЕ сюда: сырое на разбор (→ _inbox/), то что делаем сейчас (→ [02_active.md](02_active.md)), архитектурные решения (→ [05_decisions.md](05_decisions.md)).

**Тег ⏳ ждёт клиент.** Ставится в начало задачи, если её ждёт живой клиент: в досье клиента висит парная задача «развернуть / запустить / адаптировать», которая не двинется без этой. Формат — `⏳ **ждёт клиент ({клиент}) · Название.**` + ссылка на парную клиентскую задачу. Такие задачи держим вверху своего раздела и берём в спринт первыми. Тег снимается вместе с закрытием задачи.
