# Общий код плагина

markdown_links.py — единый разбор Markdown-ссылок и проверка существования
локальных целей для content-update и space-align. Зависимостей вне стандартной
библиотеки Python нет.

Правится только этот исходник. Манифест сборщика кладёт его рядом с обоими CLI;
копий в исходниках скиллов нет. Установленные скиллы импортируют соседний модуль
и работают автономно, в том числе в отдельных ZIP. Проверка сохранности переноса
остаётся отдельной частью space-align.

Для запуска CLI из исходников добавьте эту папку в PYTHONPATH.

Схема поставки выбрана с учётом документации
[Claude Code](https://code.claude.com/docs/en/plugins-reference) и
[Codex](https://developers.openai.com/plugins/build/plugins): зависимости входят
в пакет, а путь к коду не зависит от рабочей папки. Копирование общего исходника
в каждый автономный скилл — решение нашей сборки, а не требование хостов.

Проверяются inline-ссылки с title, пробелами в угловых скобках, экранированными
и вложенными скобками; полные, сокращённые и короткие reference-style ссылки;
URL-кодирование. Примеры в fenced-блоках и inline-коде не считаются ссылками.
Проверяется существование локальной цели, но не HTTP, HTML-ссылки или якоря;
модуль не является полным Markdown-рендерером. Регрессии обоих CLI —
в треке content-update.
