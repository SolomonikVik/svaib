# Управленческое пространство руководителя — каркас папок и файлов

Карта управления бизнесом для работы с AI: компания, направления, входящее и архив. Точка входа — отсюда агент понимает, что читать и куда складывать новое.

## Содержимое папки

- [01_company/](01_company/) — компания как целое: курс, команда, ключевые метрики и кросс-функциональный контекст без более узкого владельца. Читать: всегда при входе, чтобы понять состояние и курс бизнеса.
- [_inbox/](_inbox/) — входящее на разбор: материал без места в дереве. Не источник правды — записи уходят к владельцам. Читать: когда у материала ещё нет владельца.
- zz_archive/ — холодный и завершённый контекст. Читать: когда нужны старые материалы без смешивания с актуальным.
- [_templates/](_templates/README.md) — бланки файлов и папок. Читать: когда создаёшь новое направление, файл или папку — копируй образец отсюда.

## Маршруты чтения

- Как устроено управление — читать первым при управленческой работе → [operating-model](01_company/operating-model.md)
- Понять состояние и курс бизнеса → `01_company/` (`01_strategic/` — курс, `03_metrics/` — цифры)
- Работа по конкретному направлению → его папка в корне
- Разобрать неразложенный материал → `_inbox/`
- Создать новое направление, файл или папку → бланк из [_templates/](_templates/README.md)

## Связанные контексты

- Заполняется при разворачивании: внешние системы и контексты клиента, нужные для чтения этой карты.

## 🔧 Разворачивание

- Новое направление, личный контур руководителя, продукт или клиенты — когда появляется объект, которым управляют отдельно
- `_private/` — когда части контекста нужен более узкий доступ
- Правило встреч (строка в «Правилах работы») — когда с руководителем согласовано размещение встреч
- Рабочие папки (`docs/`, `contracts/` и др.) — для материалов верхнего уровня
