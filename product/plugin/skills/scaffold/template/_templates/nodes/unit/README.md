# unit — универсальный объект управления

Универсальная папка объекта управления: функции, филиала, подразделения, бизнес-направления или родительского объекта.

## Содержимое папки

- 01_overview.md — обзор объекта управления: что это, где мы сейчас, куда смотреть глубже. Читать: при первичном входе в папку.

## Связанные контексты

- Заполняется при разворачивании: родительская папка, смежные объекты управления и контекст уровня компании, если они нужны для чтения этого объекта.

## 🔧 Разворачивание

- `02_active.md` — появилась текущая работа
- `03_backlog.md` — появились отложенные задачи и идеи
- `04_progress.md` — нужна хроника событий
- `05_decisions.md` — первое зафиксированное решение
- Управленческие ракурсы (`01_strategic/`, `02_team/`, `03_metrics/`, `projects/`, `processes/`, `knowledge/`) — по живой работе в ракурсе
- Служебные папки (`_inbox/`, `zz_archive/`) — по своему потоку
- `meetings/` — правило встреч из корневого README размещает встречи здесь
- Рабочие папки клиента (`docs/`, `contracts/` и др.) — появились рабочие материалы
