# client-name — клиентский проект

Папка одного внешнего клиентского проекта: бизнес контрагента, что делаем, рабочая конфигурация, текущая работа, прогресс и решения.

## Содержимое папки

- 01_overview.md — обзор клиентского проекта: что это, где мы сейчас, куда смотреть глубже. Читать: при первичном входе в проект.
- [company.md](company.md) — бизнес контрагента: продукт, цифры, люди, стратегия. Читать: при подготовке решений и материалов по проекту.
- [people.md](people.md) — люди контрагента: роли, влияние, позиция, стиль коммуникации. Читать: перед встречей и перепиской.

## Маршруты чтения

- Быстро войти в проект → `01_overview.md`
- Подготовиться к встрече → `01_overview.md` → `people.md`
- Понять людей контрагента и коммуникацию → `people.md`
- Понять бизнес контрагента → `company.md`

## Маршруты записи

README маршрутизирует уже выбранный факт. Если информация не ложится в миссию файла, оставь её во входящем `_inbox/` до разбора.

- Факт о человеке, роли, влиянии, стиле коммуникации → `people.md`
- Факт о бизнесе контрагента: продукт, цифры, стратегия, оргструктура, технологии → `company.md`; люди в оргструктуре — ссылками на `people.md`
- Рамка проекта: суть, сроки, бюджет/условия, формат, цель, вехи → `01_overview.md`

## Связанные контексты

- `../` — клиентский портфель, если проект нужно читать в контексте других клиентов

## 🔧 Разворачивание

- `02_active.md` — появилась текущая работа по проекту
- `03_backlog.md` — появились отложенные задачи и идеи
- `04_progress.md` — нужна хроника движения проекта
- `05_decisions.md` — первое значимое решение по проекту
- `setup.md` — появилась рабочая конфигурация: инструменты, доступы, папки
- `people-{имя}.md` — `people.md` разросся: отдельный профиль человека
- `meetings/` — правило встреч из корневого README размещает встречи здесь; внутри `zz_archive/` для сырья
- `deliverables/` — появились материалы для контрагента
- `docs/` — юридические и исходные документы проекта
- Служебные папки (`_inbox/`, `zz_archive/`) — по потоку сырья и архива
