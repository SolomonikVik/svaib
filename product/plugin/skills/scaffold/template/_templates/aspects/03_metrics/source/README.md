# source — источники данных метрик

Локальные исходники клиента, где живут значения метрик: xlsx, выгрузки, экспорты. AI читает их как источник, но не нормализует.

## Содержимое папки

- `{source-file}` — исходный файл клиента со значениями метрик. Читать: когда extractor или аналитик должен прочитать фактические значения.

## Правила работы

- Только для чтения: AI не причёсывает, не переименовывает и не переписывает клиентский источник без отдельного решения.
- Для удалённых источников файла здесь может не быть: ссылка на Google Sheets, API или систему аналитики указывается в metrics-файле.
- Структуру источника читает extractor из `../extractors/`, он же должен ловить изменения раскладки.

## Связанные контексты

- [domain-metrics](../domain-metrics.md) — семантика метрик и привязка к источникам
- [extractors](../extractors/) — процедуры извлечения значений из источников
