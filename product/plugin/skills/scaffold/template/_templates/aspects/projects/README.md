# projects — карта проектов

В ракурсе проектов хранятся временные инициативы объекта управления: проекты с владельцем, горизонтом, рабочей повесткой и завершением.

## Содержимое папки

- `{project-name}/` — папка проекта с README, управленческой панелью по потребности, встречами и рабочими материалами. Читать: когда по проекту началась регулярная работа.

## Маршруты чтения

- Найти активный проект объекта управления → README нужного `{project-name}/`
- Понять, где хранить новый проект → эту карту и README родительского объекта управления

## Связанные контексты

- `{unit}/02_active.md` — текущая работа объекта управления, если проект ещё не выделен в отдельную папку
- `{unit}/04_progress.md` — хроника объекта управления, если проект влияет на общий прогресс

## 🔧 Разворачивание

- `{project-name}/` — по проекту началась реальная работа: есть владелец, горизонт, задачи, встречи или решения. Разворачивается по образцу направления: README + `01_overview`, дальше по живой работе проекта. Идея без регулярной работы остаётся в `03_backlog.md` владельца.
