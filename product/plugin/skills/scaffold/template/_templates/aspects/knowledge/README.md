# knowledge — карта знаний

В ракурсе знаний хранится обработанное знание, на которое объект управления опирается: объяснения, инсайты, выжимки, материалы и связи между темами.

Канон ракурса знаний в разработке. Базовая форма на сейчас: страницы и разделы по темам; сырьё до обработки живёт во входящем.

## Содержимое папки

- `{topic}.md` — страница знания по теме, которую объект управления переиспользует. Читать: когда нужно понять устойчивую тему, метод, правило или контекст.

## Маршруты чтения

- Найти устойчивое знание объекта управления → страницу или раздел по теме
- Понять, куда класть сырьё → README родительского объекта управления и `_inbox/`; сырьё не хранится в `knowledge/` без обработки

## Связанные контексты

- `../processes/` — регламенты и повторяемая работа
- `../_inbox/` — сырьё до обработки

## 🔧 Разворачивание

- `{topic}/` — одиночный файл перестал вмещать материалы и связи: тема разворачивается в раздел. По умолчанию раздел — не управленческий узел; по шаблону `unit/` — только если темой стали управлять как самостоятельным объектом.
