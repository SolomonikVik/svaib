# meetings — память встреч

Папка памяти встреч: обработанные выжимки встреч, сырые расшифровки уходят в `zz_archive/`.

## Содержимое папки

- `YYYY-MM-DD_{topic}_summary.md` — обработанная выжимка встречи: решения, задачи, факты, обновления файлов. Читать: когда нужна память конкретной встречи.
- zz_archive/ — сырые транскрипты и полный материал встреч. Читать: когда нужно проверить исходник или восстановить контекст.

## Маршруты записи

- Сырая расшифровка встречи → `zz_archive/YYYY-MM-DD_{topic}_transcript.md`
- Решения, задачи, факты и прогресс из встречи → канонические файлы владельцев, если они развёрнуты

## Связанные контексты

- `../README.md` — узел-владелец этой папки встреч
- `../02_active.md` — задачи и открытые вопросы после встречи, если файл развёрнут
- `../04_progress.md` — короткая хроника значимых событий, если файл развёрнут
- `../05_decisions.md` — решения, принятые на встрече, если файл развёрнут
