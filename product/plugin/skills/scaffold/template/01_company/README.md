# 01_company — компания как целое

Папка компании как целого: курс компании, общая команда, ключевые бизнес-метрики и кросс-функциональный контекст без более узкого владельца.

## Содержимое папки

- [operating-model.md](operating-model.md) — система управления компании: как стратегия превращается в работу. Читать: первым при управленческой работе.
- [01_strategic/](01_strategic/) — стратегический ракурс компании: курс и стратегические выборы. Старт: [vision.md](01_strategic/vision.md), [goal.md](01_strategic/goal.md). Читать: когда нужно понять курс компании.
- [02_team/](02_team/) — ракурс «команда»: общая команда, роли, ответственность. Старт: [01_org-structure.md](02_team/01_org-structure.md). Читать: при вопросах о людях, ролях и владельцах.
- [03_metrics/](03_metrics/) — ракурс «метрики»: ключевые бизнес-метрики и источники. Старт: [business-metrics.md](03_metrics/business-metrics.md). Читать: при вопросах о цифрах и состоянии бизнеса.
- [_inbox/](_inbox/) — входящее на разбор уровня компании. Читать: когда материал ещё не разложен по местам.
- zz_archive/ — холодный или завершённый контекст уровня компании. Читать: когда нужно найти старые материалы без смешивания с актуальным.

## Связанные контексты

- `../00_ceo/` — личный управленческий контекст руководителя, если он развёрнут и влияет на курс или решения компании

## 🔧 Разворачивание

- `01_overview.md` — нужен сводный обзор компании: состояние, фокус, дорожная карта
- `02_active.md` — появилась текущая кросс-функциональная работа
- `03_backlog.md` — появились отложенные задачи и идеи уровня компании
- `04_progress.md` — нужна хроника событий уровня компании
- `05_decisions.md` — первое зафиксированное решение уровня компании
- Новые ракурсы (`projects/`, `processes/`, `knowledge/`) — по живой работе в ракурсе
- `meetings/` — правило встреч из корневого README размещает встречи здесь
- Смысловые файлы (`glossary.md`, `speech-aliases.md`) — по живой потребности
- Рабочие папки клиента (`docs/` и др.) — появились материалы уровня компании
