# Компания — базовые метрики бизнеса

Базовый файл с ключевыми бизнес-метриками компании — теми, по которым CEO отслеживает движение бизнеса в целом.

## Источник

**Источник:** `{file}.xlsx`, лист «{sheet}».

Если источников несколько, заменить эту секцию на `## Источники` с подразделами `### {source_id}`, и в каждой метрике добавить поле `**Источник:**` со значением `{source_id}`:

```md
## Источники

### source_finance

**Источник:** `finance.xlsx`, лист «P&L».

### source_sales

**Источник:** `sales.xlsx`, лист «Pipeline».
```

Поле `**Источник:**` у метрик не указывается, если источник один: все метрики наследуют общий источник.

## Как заполнять метрики

**Имя метрики** (заголовок `### {имя}`) — каноническое: как метрика реально называется внутри компании. Краткое, однозначное, стабильное (меняется формула — имя не меняется; меняется управленческая сущность — это уже другая метрика), уникальное среди всех metrics-файлов клиента.

**Поля паспорта:**
- **Бизнес-смысл** — что метрика значит для бизнеса.
- **Как считается** — правило расчёта с явной временной логикой и способом вычисления (за период / на момент / доля чего-то от чего-то).
- **Единица** — `млн руб` / `%` / `шт` / …
- **Направление** — `рост — хорошо` / `рост — плохо` / `нейтрально`.
- **Источник** — `{source_id}` из секции `## Источники`. Указывается только если источников в файле несколько.

**Раскладка** — два взаимоисключающих варианта:
- **С группами.** Серия `## {имя группы}` (Продажи / Клиенты / Финэффективность), внутри каждой `### {имя}`. Контейнер `## Метрики` в этом варианте НЕ ставится.
- **Без групп.** Один контейнер `## Метрики`, внутри подряд `### {имя}`. Используется, когда естественных блоков метрик у CEO нет.

В шаблоне ниже — вариант с группами. Если естественных блоков нет, заменить серию `## {имя группы}` на один контейнер `## Метрики`.

Группы могут ссылаться на функциональные domain-файлы, когда те появляются:

```md
## Финансы

Развёрнутая раскладка финансовых метрик — [finance-metrics.md](finance-metrics.md).

### {Каноническое имя метрики}
...
```

Цели живут в `goal.md`. Метрики, которыми измеряется достижение цели (в OKR-модели — key results), лежат здесь как обычные метрики.

## {Имя группы — например, Продажи}

### {Каноническое имя метрики}

**Бизнес-смысл:** {что метрика значит для бизнеса}
**Как считается:** {правило с явной временной логикой и способом расчёта}
**Единица:** {млн руб / % / шт}
**Направление:** {рост — хорошо / рост — плохо / нейтрально}
