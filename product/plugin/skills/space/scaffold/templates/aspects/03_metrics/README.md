# {unit} — карта метрик

В ракурсе метрик хранится семантика показателей объекта управления: какие показатели важны, что они значат, где источник и как читать состояние.

## Содержимое папки

- [domain-metrics.md](domain-metrics.md) — паспорт метрик одной бизнес-области внутри объекта управления. Читать: когда у объекта управления появились метрики отдельной области.

## Связанные контексты

- `01_company/03_metrics/business-metrics.md` (путь от корня scaffold) — целевые метрики компании и точка входа в метрики компании
- `../01_overview.md` — обзор объекта управления: цели, команда, текущий фокус

## 🔧 Разворачивание

- `{domain}-metrics.md` — появились метрики новой бизнес-области объекта управления
- `source/` — значения метрик живут в файлах рядом со scaffold: xlsx, выгрузки, экспорты
- `extractors/` — нужны процедуры извлечения значений из локальных источников
