# processes — карта процессов

В ракурсе процессов хранится повторяемая работа объекта управления: процессы, регламенты, правила, операционные стандарты и устойчивые процедуры.

Канон ракурса процессов в разработке. Базовая форма на сейчас: один файл на устойчиво повторяемый процесс; папка появляется, когда процесс обрастает версиями, чек-листами или материалами.

## Содержимое папки

- `{process-name}.md` — регламент одного повторяемого процесса. Читать: когда нужно выполнить или проверить процесс.

## Маршруты чтения

- Описать новый процесс → шаблон `process.md` из папки шаблонов
- Отличить процесс от проекта → эту карту и README родительского объекта управления

## Связанные контексты

- `../projects/` — временные инициативы; внедрение процесса может быть проектом
- `../knowledge/` — обработанное знание, которое процесс переиспользует

## 🔧 Разворачивание

- `{process-name}/` — процесс оброс версиями, чек-листами или материалами: файл разворачивается в папку с тем же именем и миссией. По умолчанию папка процесса — не управленческий узел; по шаблону `unit/` — только если процессом стали управлять как самостоятельным объектом
