# clients — клиентский портфель

Родительский объект управления для портфеля клиентов: появляется, когда клиентскими отношениями управляют отдельно — есть свой владелец, метрики и ритуалы.

## Содержимое папки

- `{имя-клиента}/` — папка одного клиентского проекта: контрагент, проект, рабочая конфигурация и операционная работа. Читать: когда нужна память этого внешнего проекта.

## Связанные контексты

- `../01_company/` — компания как целое, если клиентский портфель связан с общими целями или метриками

## 🔧 Разворачивание

- Новые клиентские проекты — по шаблону `client-name/`, папка называется именем клиента
- Управленческая панель, управленческие ракурсы, служебные папки, рабочие папки клиента — по живой работе портфеля
