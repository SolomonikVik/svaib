# product — продукт как объект управления

Особый корневой объект управления для продукта компании: что поставляется клиентам, как устроено, куда развивается и как управляется.

Канон продукта как объекта управления в проработке. Базово продукт — постоянный объект управления: то, что компания поставляет клиентам, а не временный проект.

## Содержимое папки

- 01_overview.md — обзор продукта: состояние, фокус и ближайшее направление. Читать: при первичном входе в продуктовый контекст.
- [profile.md](profile.md) — паспорт продукта: позиционирование, портрет клиента, границы, бизнес-модель. Читать: при вопросах о сути продукта и его рынке.

## Связанные контексты

- `../01_company/` — компания как целое, если продукт связан с общим курсом, метриками или командой

## 🔧 Разворачивание

- `02_active.md` — появилась текущая работа
- `03_backlog.md` — появились отложенные задачи и идеи
- `04_progress.md` — нужна хроника событий
- `05_decisions.md` — первое зафиксированное решение
- `architecture.md` — внутреннее устройство продукта стало важно для управления
- Управленческие ракурсы (`01_strategic/`, `02_team/`, `03_metrics/`, `projects/` и др.) — по живой работе в ракурсе
- Служебные папки (`_inbox/`, `zz_archive/`) — по своему потоку
- `meetings/` — правило встреч из корневого README размещает встречи здесь
- Рабочие папки клиента (`docs/` и др.) — появились рабочие материалы
