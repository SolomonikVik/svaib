# infrastructure — шаблоны служебных папок

Шаблоны служебных папок scaffold: входящее до разбора и холодный контекст. Эти папки помогают агенту не смешивать сырьё, актуальную память и архив.

## Содержимое папки

- [_inbox/](./_inbox/) — входящее до разбора. Читать: когда узлу нужен локальный буфер сырья.
- zz_archive/ — холодный или завершённый контекст. Читать: когда узлу нужен архив рядом с владельцем.

## Правила работы

- Служебные папки не являются управленческими узлами. В них нет `AGENTS.md` и `CLAUDE.md`; агент читает локальный README папки, чтобы понять роль контейнера.
