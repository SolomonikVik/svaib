# usage — учёт использования скиллов

Файл на машину: `usage/<хост>.md`, где `<хост>` — имя машины латиницей, без пробелов и точек (`macbook-anna.md`). Так Google Drive с двух устройств и git не конфликтуют. Внутри — одна таблица с шапкой ниже; строка на запуск скилла или его этап, дописывается в конец.

**Писатель.** Строку кладёт только инструмент, читающий транскрипт сессии; агент цифры по памяти не вписывает, не знает — оставляет клетку пустой. Сегодня такого инструмента нет: файлы не заводятся, пока он не появится. Покрытие по средам: `claude-code` — хук завершения с транскриптом · `cowork` — тот же хук из плагина · `codex` — отдельный `hooks.json`, пока не поставляется · `server` — свой учёт на сервере.

## Колонки

- `дата` — начало запуска, `YYYY-MM-DD HH:MM+03:00`, с часовым поясом.
- `скилл`, `версия` — имя и версия скилла из его шапки; версия поставки целиком — в `setup.md`, когда появится.
- `этап` — шаг многошагового скилла; строка на весь запуск — `—`.
- `харнес` — имя и версия через пробел: `claude-code 2.1.217` · `cowork` · `codex 0.154` · `server`.
- `модель` — идентификатор модели.
- `ОС`, `машина` — система с версией и имя хоста.
- `кто` — инициал запустившего; хуку недоступен: заполняет скилл или остаётся пустым.
- `материал ток` — объём входного материала в токенах (транскрипт, книга метрик), чтобы нормировать расход; считает скилл, знающий свой вход.
- `ток ввод`, `ток вывод`, `кэш чтение`, `кэш запись` — четыре вида токенов основного контекста раздельно; сумма без разбивки цену искажает.
- `ходов`, `инстр` — ходов модели и вызовов инструментов.
- `субаг`, `субаг ток` — число субагентов и их токены суммарно; в основные колонки они не входят.
- `сек` — от старта до завершения.
- `исход` — `завершён` · `оборван` · `ошибка`.
- `прогон` — идентификатор сессии; транскрипт по нему ищется на той же машине.
- `оценка` — оценка пользователя от 1 до 5, если дал; единственная клетка, которую дописывают позже.
- Стоимость в деньгах не пишется: считается потом из токенов и модели. Внутри клетки нет `|` и переносов строк.
