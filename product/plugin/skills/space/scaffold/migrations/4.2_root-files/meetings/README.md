# meetings — память встреч

Папка памяти встреч. Одна встреча — одна папка; решения, задачи и факты из встречи живут у своих владельцев, здесь — сама встреча.

## Содержимое папки

Индекс встреч: строка на встречу, свежие сверху, ~10 слов о главном.

## Папка встречи

Имя: `YYYY-MM-DD_{[периодичность-][объект-]тип}[_{тема}]/`. Обязательны дата и тип; остальное пишется, только если не выводится из контекста:

- периодичность — только у регулярной встречи: `daily`, `weekly`, `monthly`, `quarterly`, `semiannual`, `annual`;
- объект — если его не задаёт папка: в `{имя}/meetings/` имя не повторяем, в общей папке пишем;
- тема — чтобы различить похожие встречи или когда тема главная.

Внутри — файлы с фиксированными именами: `agenda.md` (повестка), `transcript.md` (расшифровка), `summary.md` (выжимка — источник правды о встрече), `protocol.md` (протокол для участников). Лежит только то, что у встречи есть.

Тип — зачем собирались:

| Тип | Что за встреча |
|---|---|
| `sync` | планёрка: состояние работы, блокеры, следующие шаги |
| `one-to-one` | руководитель и сотрудник: обратная связь, развитие, сложности |
| `review` | итоги периода или проекта против плана |
| `strategy` | направление, цели, ставки, приоритеты |
| `brainstorm` | идеи к одной задаче; идеи не становятся задачами сами |
| `negotiation` | переговоры об условиях со стороной с другими интересами |
| `interview` | собеседование кандидата |
| `general` | тип не определить или форматов несколько |

Новый тип добавляет человек; агент тип не придумывает — берёт `general`.

Подпапка внутри `meetings/` (`one-to-one/`, `quarterly/`) — когда здесь живут несколько серий или встреч слишком много.

## Маршруты записи

- Материалы встречи → её папка; строка о встрече → индекс выше
- Решения, задачи, факты и прогресс из встречи → канонические файлы владельцев, если они развёрнуты
