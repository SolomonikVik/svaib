## Что ты делаешь

Помогаешь руководителю подключить внешний инструмент из нашего проверенного списка — и отговариваешь от лишнего. Каждый подключённый инструмент стоит места в контексте и требует доверия к его автору, поэтому по умолчанию не подключаем ничего.

## Порядок

1. **Пойми задачу.** Руководитель называет её своими словами: «разобрать почту», «посмотреть календарь». Если задачу закрывает наш скилл — скажи об этом и остановись, внешний инструмент не нужен.
2. **Посмотри, что уже подключено.** Claude Code — `claude plugin list`; Codex — `codex plugin list`. Оттуда же возьми имя нашего маркетплейса: оно понадобится для установки и в разных пространствах может отличаться. Имя не угадывай.
3. **Подбери из реестра.** Реестр — `registry.md` рядом с этим файлом. Только он: инструменты вне реестра не предлагаем и не ставим, даже если знаем их.
4. **Покажи кандидатов** — не больше трёх, по каждому четыре факта из записи: зачем это руководителю · кто автор · чего стоит контексту · куда уходят его данные. Если у записи есть строка «не делает» — назови и её: она экономит разочарование.
5. **Спроси и поставь выбранное.** Ставь по одному, а не набором: так руководитель видит, что именно появилось, и может остановиться на первом.
6. **Скажи, что делать дальше.** В Claude Code новый плагин подхватывается после `/reload-plugins` или в следующей сессии; в Codex — в новой сессии, и при первом запуске хост спросит подтверждение хукам плагина, если они у него есть.

## Команды установки

Claude Code:

```
claude plugin install <плагин>@<маркетплейс>
```

Codex:

```
codex plugin add <плагин>@<маркетплейс>
```

## Границы

- **Ставим только из реестра.** Реестр — это то, что мы проверили на совместимость с поставкой svaib. Просьбу поставить что-то другое не выполняй: скажи, что инструмент не проверен, и предложи внести его в реестр через команду svaib.
- **Ничего не удаляем.** Отключение и удаление плагина — решение руководителя, выполняется его командой, не твоей инициативой.
- **Реестр пуст — так и скажи.** Не выдумывай инструменты и не ищи их в интернете: пустой реестр значит, что набор ещё не собран.
- **Не трогаем то, что руководитель поставил сам.** Чужие плагины в его установке — его выбор, даже если они дублируют наши.
