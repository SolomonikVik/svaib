# Реестр рекомендованных инструментов

Внешние инструменты, которые мы проверили на совместимость с поставкой svaib. Скилл `space-toolbox` предлагает только то, что есть здесь.

Набор собирается: первые записи — почта, календарь и документы Google и Microsoft.

## Форма записи

```markdown
## <имя инструмента>

- **Задача:** что руководитель получает, одной строкой на его языке
- **Вид:** плагин · коннектор · MCP-сервер
- **Подключение:**
  - Claude: команда или путь в настройках, что нужно от руководителя (вход в аккаунт, согласие администратора)
  - Codex: то же для Codex; нет пути — «нет»
- **Автор:** кто сопровождает инструмент
- **Контекст:** сколько токенов добавляет в каждую сессию
- **Данные:** куда уходят данные руководителя и что видит сторонний сервис
- **Не делает:** чего от него ждут, но он этого не умеет
- **Проверено:** дата и версия, на которой проверяли
```

Вид различает, что мы контролируем. **Плагин** из нашего маркетплейса мы пиним и обновляем сами. **Коннектор** — сервис хоста: коннектор claude.ai включается в настройках аккаунта, в Codex это плагин из маркетплейса `openai-curated-remote`; версию держит вендор. **MCP-сервер** подключается командой `claude mcp add` / `codex mcp add`; версию держит его автор.

## Правила ведения

- Запись появляется только после проверки: подключение в обеих средах или явное «нет» для той, где пути нет, и стоимость контекста. У плагина ещё состав (`claude plugin details`) и отсутствие хуков на `UserPromptSubmit`, `PostToolUse`, `SessionStart` и `Stop` — на них работает наша навигация.
- Бюджет набора — не больше 1000 токенов в каждой сессии на все рекомендованные инструменты вместе.
- Источник и пин версии плагина живут в записи нашего маркетплейса, не здесь: здесь — язык для руководителя.
- Инструмент, который пишет в управленческое пространство, в реестр не входит: за структуру пространства отвечает канон scaffold.

## Google: почта, календарь, диск

- **Задача:** партнёр читает почту и готовит ответы, видит встречи и их участников, находит и читает документы на Диске
- **Вид:** коннектор
- **Подключение:**
  - Claude: claude.ai → Настройки → Коннекторы → Gmail, Google Calendar, Google Drive → вход в Google. В Claude Code коннекторы видны, когда вход выполнен аккаунтом claude.ai. На планах Team и Enterprise их сначала включает администратор
  - Codex: `codex plugin add gmail@openai-curated-remote`, так же `google-calendar`, `google-drive`, `google-contacts` → вход в Google. Codex должен быть авторизован через аккаунт ChatGPT
- **Автор:** коннекторы хоста — Anthropic и OpenAI, сервис — Google
- **Контекст:** в Claude Code инструменты подгружаются по запросу — в каждой сессии только их имена; в Codex не замеряли
- **Данные:** письма, события и файлы читает хост (Anthropic или OpenAI) в момент запроса; Anthropic заявляет, что не обучает модели на данных этих коннекторов
- **Не делает:** в Claude не читает контакты и вложения писем; ничего не разбирает сам, без запроса; письмо отправляет только после подтверждения
- **Проверено:** 2026-09-25 — записи есть в каталогах обеих сред (Codex 0.156.1: gmail 0.1.10, google-calendar 1.2.7, google-drive 0.1.16, google-contacts 1.0.0); вживую в Claude Code 2026-09-25 работает Drive: список и метаданные файлов; Drive — канал книг метрик скилла `metrics-values`, у клиента с 2026-08-28. 2026-10-01 в Codex проверены чтение и отправка Gmail с доставкой, чтение Google Calendar, поиск и чтение сохранённых карточек Google Contacts 1.0.0. Для «Других контактов» поиск работает, чтение полной карточки возвращает 404. Версии Gmail и Calendar в этом прогоне отдельно не зафиксированы; их проверка в Claude остаётся открытой

## Microsoft 365: Outlook, Teams, SharePoint

- **Задача:** партнёр читает рабочую почту Outlook и готовит ответы, видит встречи, находит файлы в SharePoint и OneDrive
- **Вид:** коннектор
- **Подключение:**
  - Claude: claude.ai → Настройки → Коннекторы → Microsoft 365 → вход рабочей учётной записью Microsoft. Первый раз нужно согласие глобального администратора организации; отправку писем и изменение событий администратор включает отдельно
  - Codex: `codex plugin add outlook-email@openai-curated-remote`, так же `outlook-calendar`, `teams`, `sharepoint` → вход в Microsoft. Codex должен быть авторизован через аккаунт ChatGPT
- **Автор:** коннекторы хоста — Anthropic и OpenAI, сервис — Microsoft
- **Контекст:** в Claude Code инструменты подгружаются по запросу — в каждой сессии только их имена; в Codex не замеряли
- **Данные:** письма, события и файлы читает хост (Anthropic или OpenAI) в момент запроса
- **Не делает:** в Claude не работает с личными ящиками @outlook.com и @hotmail; без администратора организации не подключится
- **Проверено:** 2026-09-25 — записи есть в каталогах обеих сред (Codex 0.156.1: outlook-email 0.1.8, outlook-calendar 0.1.9, teams 0.1.9, sharepoint 0.1.8); вживую не подключали
