# Skills

## Кратко

Скиллы, которые едут клиенту в составе плагина. Раскладка — по разделам: контур управления, пространство, роли партнёра и служебные шаги. Имя скилла склеивается из пути: клиент видит плоский список `svaib:<имя>`, иерархии в нём не видно.

Норма раскладки и имён — skills-layout.md.

## Раскладка

Каталог = раздел, внутри — каталог скилла с `SKILL.md` и его комплектом (`scripts/`, `prompts/`, `references/`, `schema/` — по необходимости).

```
skills/
├── rhythm/    ритм управления: встречи и отчёты
├── metrics/   цели и показатели
├── space/     само управленческое пространство
├── roles/     роли партнёра — по одной на контур
└── tools/     служебные шаги: обработка и доставка
```

Разделы контуров — семь по [Svaib Management System](../../methodology/ontology/01_svaib-management-system.md); каталог заводится, когда в нём появляется первый скилл. Подраздел заводится с третьего скилла: два скилла с общим куском имени — не уровень, а двухсловная задача.

**В пакете раскладки нет.** Сборщик уплощает: `skills/rhythm/meeting-agenda/` собирается в `skills/rhythm-meeting-agenda/`, где имя каталога совпадает с `name`, как требует платформа.

## Имя

`<раздел>-<задача>`, где раздел называет сторону управления или объект. Раздел `tools` называет сорт скилла, а не предмет, — в имя он не входит.

- **Раздел в имени не повторяет каталог:** путь склеивается, а не дублируется.
- **Имя — задача руководителя, а не механизм:** `meeting-agenda`, не `agenda-builder`.
- **Версии в имя не входят:** принятая версия занимает каноническое имя, прежняя получает `-old`.
- **Форма:** латиница, kebab-case, до трёх слов.

## Фактический состав

Продуктовый реестр управленческих скиллов и обязательств — [skills-catalog.md](../../skills-catalog.md). Ниже — фактические исходники этой папки.

| Исходник | Имя у клиента | Назначение |
|---|---|---|
| `rhythm/meeting-agenda` | `rhythm-meeting-agenda` | Повестка к предстоящей встрече: SKILL.md, каркас формы, валидатор и поиск принятых решений |
| `rhythm/meeting-debrief` | `rhythm-meeting-debrief` | Разбор состоявшейся встречи — основная версия (линия v4e) |
| `rhythm/meeting-debrief-old` | `rhythm-meeting-debrief-old` | Предыдущая версия разбора — только по явной просьбе |
| `metrics/values` | `metrics-values` | Живые значения метрик из книг руководителя: SKILL.md и три скрипта (чтение, производные, кэш снимка) |
| `space/scaffold` | `space-scaffold` | Устройство пространства и его версия: шаблоны (`templates/`, корень нового пространства — `templates/root/`), миграции; спецификации файлов сборщик тянет из методологии |
| `space/align` | `space-align` | Проверка и выравнивание пространства по канону scaffold; канон читает из публичного релиза |
| `space/toolbox` | `space-toolbox` | Рекомендованные внешние инструменты и их подключение |
| `space/onboarding` | `space-onboarding` | Освоение svaib: знакомство, этапы человека и компании, отметки пройденного, подключение рабочего места; справки Google Диска, git и Obsidian; каталог этапов и их методологию сборщик тянет из методологии |
| `roles/strategy` | `roles-strategy` | Роль стратега: позиция, принципы, что читает, какими скиллами оперирует |
| `tools/send-telegram` | `send-telegram` | Доставка результата в Telegram |
| `tools/transcript-extract` | `transcript-extract` | Выжимка по темам из транскрипта |
| `tools/content-update` | `content-update` | Запись согласованных правок в файлы пространства |
| `tools/email-assistant` | — | Триаж входящей почты; в поставку не входит |
