# Plugin — деплоимый пакет Second Value AI Brain

## Кратко

Собранный пакет для клиента: наш продуктовый слой поверх scaffold-структуры. Plugin содержит методологию в исполняемом формате. Источник — [методология](../methodology/README.md): там правят карточки ролей и workflow, здесь — их поставляемая форма, и она не обязана совпадать с источником целиком. Файлы из методологии сюда не переносят.

**Статус:** Skills — уже реальные, работающие скиллы (см. [skills/README.md](skills/README.md)). Hooks — навигация по пространству (карта и подкарты узлов), спецификация файла перед записью, ловля отложенных действий, учёт использования скиллов в `.svaib/usage/` ([hooks/README.md](hooks/README.md)). Работают при доставке плагином в Claude Code, Codex и Cowork «Only on this computer»; в облачном Cowork хук не видит пространство, навигацию там несёт инструкция агента. Agents — по-прежнему скелет, наполнение после обкатки методологии на первых клиентах.

## Компоненты

| Что | Папка | Что делает                                                                                                       |
|-----|-------|------------------------------------------------------------------------------------------------------------------|
| Skills | `skills/` | Методология в исполняемом формате: разбор встреч, повестка, метрики, выравнивание пространства по канону, доставка в Telegram. Состав и статусы — [skills/README.md](skills/README.md) |
| Hooks | `hooks/` | Детерминированные правила сессии: карта пространства и подкарты узлов, спецификация файла перед записью, запрет отложенных действий, учёт использования скиллов. Среды и их ограничения — [hooks/README.md](hooks/README.md) |
| Agents | `agents/` | Скелет. Автоматизация: диспетчер задач, обновление документации                                                  |
| Roles | `skills/roles/` | Роли партнёра: с какой позицией и знанием контура он входит в разговор. Едут скиллами — каталога `commands/` в спецификации манифеста плагина Codex нет, а custom prompts помечены deprecated. Внутренние роли svaib клиенту не поставляются. Упаковка из карточки — skills-layout, «Роли» |

## Как пакет попадает к клиенту

Собирается сборщиком — dev/plugin-builder/. Он берёт из этой папки то, что перечислено в профиле клиента, чинит пути под установку и проверяет результат. Сам сборщик — инженерная оснастка, частью продукта не является.

Состав под конкретного клиента задаётся профилем; профили живут рядом с клиентом, в `clients/`.
