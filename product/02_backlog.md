# Product — бэклог

## Кратко

Полный список задач направления на будущее. Источник для плана недели (weekly-planning). Задачи уже разобраны (из inbox) и ожидают выполнения.

Структура — по двум осям архитектуры (decision №4, 2026-04-27): **горизонталь** (общие слои) и **вертикали** (управленческие циклы). Скиллы и прочее — отдельно.

**Работа с файлом:** plan — дописывать по мере появления задач (из `_inbox/` при разборе, из встреч, из инсайтов). Выполненная задача — `[x]` + перенос в [03_progress.md](03_progress.md). Задача пишется с достаточным контекстом: понятно что делать без открытия других файлов. Что сюда: конкретные задачи развития direction'а. Что НЕ сюда: сырое на разбор (→ _inbox/), то что делаем сейчас (→ [02_active.md](02_active.md)), архитектурные решения (→ [04_decisions.md](04_decisions.md)).
