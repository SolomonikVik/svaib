# Memory — методология и исследования слоя memory

Методология контекстной памяти, спецификации её компонентов и исследовательские материалы. Рабочие правила создания и ревизии файлов задаёт [scaffold/02_file-spec.md](../scaffold/02_file-spec.md).

**Границы:** КАКИЕ сущности существуют → `../ontology/`. КАК с ними работать (decision frames, meeting analysis, онбординг) → `../`.

## Файлы

- [01_context_memory.md](01_context_memory.md) — прежний исследовательский черновик методологии контекстной памяти
- [01_context-memory_new.md](01_context-memory_new.md) — актуализированная методология: организация информации, сбор контекста, актуализация и уровни управляемости; подготовлена для замены прежнего файла
- [navigation-spec.md](navigation-spec.md) — требуемый результат навигации: состав карты, моменты подачи и правила поведения агента
- [navigation-workflow.md](navigation-workflow.md) — текущая реализация спецификации: генератор, хуки, события сред, настройки, поставка и проверки
- [navigation-eval.md](navigation-eval.md) — продуктовый контракт проверки навигации: типы кейсов, целевые механизмы, метрики и правила сравнения
- [file_spec.md](file_spec.md) — накопленные исследования формата единицы памяти; не канон
- [update-protocol.md](update-protocol.md) — черновик протокола обновления памяти
