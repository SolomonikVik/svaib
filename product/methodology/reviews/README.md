# Ревью

Общие источники и история совместной разработки трёх ревью. Пакет каждого скилла лежит в папке своего ракурса.

## Содержимое папки

- _plan.md — совместный план и отложенные правки. Читать: при сверке общего контекста.
- [research.md](research.md) — внешние источники, общие для всех ревью. Читать: при исследовании и спецификации любого ревью.
- `_inbox/` — ответы хранителя канона о месте хранения и имени сохранённого ревью. Читать: при решении, где и как хранить ревью.
- [Ревью проекта](../aspect-projects/review/README.md) — ракурс «Проекты».
- [Ревью подразделения](../aspect-team/unit-review/README.md) · [ревью человека](../aspect-team/person-review/README.md) — ракурс «Команда».
