# Роли и идентичность партнёра

Здесь собираем методологию ролей svaib-партнёра, а в дальнейшем — soul и связанные настройки его характера и идентичности. В этой папке живут общие описания и шаблоны; персональные настройки партнёра — в пространстве пользователя.

## Роли

- [strategy.md](strategy.md) — Стратег: держит фокус руководителя на движении к стратегическим целям. Первая версия, 15.09.

## Содержимое

- [role-template.md](role-template.md) — минимальный шаблон роли и правила его заполнения. На его основе будут оформляться конкретные роли.
- _plan.md — план трека: рамка, решения 15.09, опоры, находка про память, шаги, открытые вопросы.

## Опоры для описания ролей

Понимание устройства управления, связей и источников информации — часть экспертизы роли. При описании роли опирайся на нужные разделы источников ниже; общие правила в карточке не повторяй.
