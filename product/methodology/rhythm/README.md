# Rhythm — методология ритма управления

Папка методологии ритма управления: подготовка повестки, анализ прошедшей встречи, ревью состояния объекта.

## Содержимое папки

- [agenda/](agenda/README.md) — методология подготовки аналитической повестки. Читать: при работе с подготовкой к встрече.
- [meeting-analysis/](meeting-analysis/README.md) — методология анализа прошедшей встречи. Читать: при работе с разбором встречи.
- review/ — ревью состояния объекта управления, сотрудника, движения цели. Читать: при работе над скиллом «Ревью» (в разработке, требования не сформированы).
