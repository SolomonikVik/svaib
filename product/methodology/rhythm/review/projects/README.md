# Прогресс (ревью) проекта — методология

Разработка клиентского скилла «Прогресс (ревью) проекта»: обзор одного проекта целиком — что реально изменилось, ведёт ли он к цели, двигается или стоит. Каталог: [5.1](../../../../skills-catalog.md). Спрос: ❗ Л.

## Содержимое папки

- [research.md](research.md) — исходный запрос, представление Виктора, находки по досье Л. и решения по рамке. Читать: при работе над исследованием (в работе).
- _plan.md — план разработки и Session Handoff. Читать: при продолжении работы.
- `_inbox/` — отчёты агентов и вердикты внешних моделей по исследованию. Читать: когда нужен полный след находки.

## Связанные контексты

- Ревью — зонтик: проекты, подразделение, человек.
- [Agenda](../../agenda/README.md) — повестка встречи: соседний скилл ритма, с которым нужно разграничить результат.
