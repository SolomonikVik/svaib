# Meeting analysis — методология анализа встреч

Принципы и контракты анализа прошедшей встречи: извлечение, выжимка, надстройки и оценка качества.

## Содержимое папки

- [eval.md](eval.md) — оценка сохранности несущего смысла встречи. Читать: при определении качества результата.
- [meeting_analysis.md](meeting_analysis.md) — методология извлечения и сборки выжимки. Читать: при работе с анализом транскрипта.
- [meeting_overlays.md](meeting_overlays.md) — надстройки над выжимкой. Читать: при работе с результатами анализа.
- _inbox/ — рабочие материалы и эксперименты. Читать: когда нужен их полный след.
- _plan/ — план методологической переработки для v4. Читать: при продолжении работы.
