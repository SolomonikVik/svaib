# Agenda — методология подготовки к встрече

Спецификация аналитической повестки, workflow, чек-лист качества и история исследования скилла «Повестка управленческой встречи». Разработано по skill-factory-v; продуктово-методологический блок закрыт 01.09.2026, инженерная упаковка беты — план Эрика.

## Содержимое папки

- [research.md](research.md) — исходный запрос, что проверяли, единый вывод (`final`). Читать: когда нужен контекст «почему так».
- [agenda_spec.md](agenda_spec.md) — спецификация результата: цель повестки, состав по блокам, форма и язык (`final`, v2). Читать: когда нужен контракт результата.
- [workflow.md](workflow.md) — как агент идёт от запроса к повестке: вход, рамка, оба участника, сборка по спеке, проверка читателем, выдача (`final`, v1). Читать: при работе над способом подготовки повестки.
- [eval.md](eval.md) — чек-лист качества повестки: что обязательно, что недопустимо, правило PASS/FAIL (`draft`; финал — по итогам беты у клиентов). Читать: при проверке готовой повестки.
- [canon-proposal.md](canon-proposal.md) — противоречия внутри канона, всплывшие на бете; только drama-gaps, «где встали» (`draft`). Читать: перед правкой спеки или eval.
- [agenda-prompt.md](agenda-prompt.md) — прежние варианты prompt (эксперимент 13.08), история. Читать: когда нужен след эксперимента.
