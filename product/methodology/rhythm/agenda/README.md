# Agenda — методология подготовки к встрече

Целевой образ аналитической повестки, методологический prompt и рабочие материалы по её разработке.

## Содержимое папки

- [agenda.md](agenda.md) — целевой образ аналитической повестки. Читать: когда нужен контракт результата.
- [agenda-prompt.md](agenda-prompt.md) — методологический prompt сборки повестки. Читать: при работе над способом её подготовки.
- [_plan.md](_plan.md) — план разработки повестки. Читать: при продолжении работы.
- _inbox/ — материалы тестов и экспериментов. Читать: когда нужен их полный след.
