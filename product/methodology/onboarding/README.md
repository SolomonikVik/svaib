# Онбординг — методология освоения svaib

Единый вход в методологию онбординга компании и человека: этапы освоения, результат скилла `onboarding`, исследование и workflow.

## Содержимое папки

- [onboarding.md](onboarding.md) — два трека, этапы, признаки закрытия и состояния; источник каталога для сборки плагина. Читать: когда нужен состав пути освоения.
- _plan.md — план разработки скилла по фабрике: Session Handoff и чек-лист этапов. Читать: первым, когда продолжаешь разработку.
- [research.md](research.md) — исходный запрос, вопрос исследования, находки, спорное и вывод. Читать: когда нужен контекст «почему так».
- [onboarding_spec.md](onboarding_spec.md) — спецификация результата: ценность, «где я остановился», отметка этапа, знакомство, подключение, границы. Читать: когда нужен контракт результата.
- [workflow.md](workflow.md) — как агент идёт от фразы человека к результату и сверка со спецификацией скилла. Читать: при работе над способом ведения онбординга.

## Маршруты записи

- Этапы и признаки закрытия → [onboarding.md](onboarding.md); результат скилла → [onboarding_spec.md](onboarding_spec.md); способ ведения → [workflow.md](workflow.md).
- Инженерная реализация, MCP и сборка → трек IT-онбординга; инструкции пользователю → [документация продукта](../../docs/instructions/README.md).
