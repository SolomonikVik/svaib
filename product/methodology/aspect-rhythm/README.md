# Rhythm — методология ритма управления

Папка методологии ритма управления: подготовка повестки, анализ прошедшей встречи, ревью состояния объекта.

## Содержимое папки

- [agenda/](meeting-agenda/README.md) — методология подготовки аналитической повестки. Читать: при работе с подготовкой к встрече.
- [meeting-analysis/](meeting-debrief/README.md) — методология анализа прошедшей встречи. Читать: при работе с разбором встречи.
- [review/](review/README.md) — три ревью: проекта, подразделения, человека; общие источники и план. Читать: при работе над любым ревью.

## Связанные контексты

- [Svaib Management System](../ontology/01_svaib-management-system.md) — место ритма управления в системе менеджмента.
