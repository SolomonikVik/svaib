# Ревью подразделения — методология

Разработка клиентского скилла «Ревью подразделения»; подразделение — так клиенты называют юнит. Каталог: 3.5.

## Содержимое папки

- _plan.md — этапы разработки и Session Handoff. Читать: при продолжении работы.
- [research.md](research.md) — запрос и рамка исследования. Читать: при исследовании результата ревью.
- [unit-review_spec.md](unit-review_spec.md) — спецификация результата: цель, блоки ревью, макет. Читать: при сборке ревью и его проверке.
- [workflow.md](workflow.md) — как агент идёт от запроса к ревью: на что опирается, в каком порядке, где нужен отдельный взгляд. Читать: при сборке скилла и прогонах.
- [eval.md](eval.md) — Product Eval: принимается ли готовое ревью. Читать: при приёмке прогонов.
