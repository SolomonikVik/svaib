# Ревью

Разработка трёх клиентских ревью: проекта, подразделения, человека. Здесь — общее для всех трёх; у каждого ревью своя подпапка.

## Содержимое папки

- _plan.md — план по трём ревью: порядок работы и правки, отложенные на конец. Читать: при старте работы над любым ревью.
- [research.md](research.md) — внешние источники, общие для всех ревью. Читать: при исследовании и спецификации любого ревью.
- `_inbox/` — ответы хранителя канона о месте хранения и имени сохранённого ревью. Читать: при решении, где и как хранить ревью.
- [projects/](projects/README.md) — Прогресс (ревью) проекта. Читать: при работе над ревью проекта.
- [units/](units/README.md) — ревью подразделения. Читать: при работе над ревью подразделения.
- [people/](people/README.md) — ревью человека. Читать: при работе над ревью человека.
