# Ontology — какие сущности существуют

Справочник сущностей Second Value AI Brain: типы файлов, их поля, связи, правила размещения.

**Границы:** Протоколы и decision frames → `../`. Готовые шаблоны → `../../plugin/skills/scaffold/template/`.

## Файлы
Все файлы требуют тщательного пересмотра не опираться как на SOT

- [01_ontology-draft.md](01_ontology-draft.md) — первый черновик интегральной онтологии управления SVAIB; рабочая гипотеза, не SOT
- [ontology.md](ontology.md) — полная спецификация ❗️ файл устарел и требует тщательной переработки - на него не опираться

- [entities.md](entities.md) — атомарные сущности (решение, задача, идея и др.) 
- [behavioral_patterns.md](behavioral_patterns.md) — поведенческие паттерны на встречах (сопротивление, увод темы и др.)
- [rituals.md](rituals.md) — каталог ритуалов (повторяющиеся управленческие процессы)
- [management_cycles.md](management_cycles.md) — управленческие циклы как онтологическая категория выше ритуалов
- [protocol_format.md](protocol_format.md) — schema семейства протоколов: маппинг сущностей → секции, приоритеты, общие правила

Действующий канон формата файла (YAML, шапка, секции, связи) → [../scaffold/02_file-spec.md](../scaffold/02_file-spec.md).
