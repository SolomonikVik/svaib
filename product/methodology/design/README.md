# design — оформление результатов svaib

Единое место для того, как выглядит всё, что svaib отдаёт руководителю. Автор спецификации переносит форму отсюда в спецификацию.

## Содержимое папки

- [results.md](results.md) — дизайн результатов: макет, универсальные элементы вида любого результата, словарь знаков и приёмы по выбору спецификации. Читать: когда пишешь спецификацию результата или её макет.

## Маршруты чтения

- Пишу спецификацию или макет результата → [results.md](results.md)
- Нужны цвета, шрифты, логотип, слайды, PDF, диаграммы → бренд svaib

## Правила работы

- После правки дизайна сверь с ним спецификации результатов.

## Связанные контексты

- Бренд svaib — палитра, шрифты, логотип, гайды для слайдов, PDF, диаграмм и HTML. Цвета и шрифты берём оттуда, не копируем.

## 🔧 Разворачивание

- `charts.md` — когда результаты начнут показывать графики
