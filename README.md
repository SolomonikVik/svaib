# svaib

AI-компания, которая делает предпринимателей сильнее через AI.

## Что мы строим

**Миссия:** помогаем предпринимателям строить сильный бизнес вместе с AI — сохраняя человеческое.

Цель — построить международную AI-компанию с классным продуктом, клиентами по всему миру и небольшой увлечённой командой.

## Продукт

**Second Value AI Brain** — полноценный AI-партнёр для руководителя, который знает бизнес, помогает управлять и достигать целей.

Двойной смысл `value`: **второй взгляд** — параллельная точка зрения для проверки решений; **ценностное ядро** — система держит ценности руководителя и не даёт отклониться от них под давлением рутины.

Second Value AI Brain объединяет три слоя:

1. **Данные** — упорядоченный бизнес-контекст руководителя.
2. **Память** — понимание связей, актуальности и необходимого контекста.
3. **AI-помощники** — работа с управленческими задачами по запросу и автоматически.

Продукт строится вокруг управленческих циклов: стратегия, команда, метрики, встречи, продукт, финансы, проекты, маркетинг и продажи.

Данные остаются у клиента. Методология и автоматизация поставляются в виде обновляемого `plugin` поверх выбранного AI-интерфейса.

## Стадия

Сейчас: первые платящие клиенты, привлечён ангельский раунд.

К концу 2026 года svaib должна стать молодой продуктовой AI-компанией:

- целостная бета-версия Second Value AI Brain;
- 10–20 платящих клиентов;
- минимальная команда;
- работающий канал привлечения клиентов.

## AI-first

Мы стремимся максимально использовать AI не только в продукте, но и внутри компании. Агенты участвуют в разработке, исследованиях, клиентской работе, маркетинге и внутренних процессах.

Цель — минимально возможная человеческая команда с максимально сильной AI-системой.
